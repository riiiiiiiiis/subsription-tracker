## Исходный README

# qoder - Subscription Tracker

Приложение для управления подписками на React + Supabase. Отслеживайте расходы, получайте аналитику и управляйте подписками с синхронизацией в реальном времени.

## Возможности

- Управление подписками (добавление, редактирование, удаление)
- Аналитика расходов и категоризация
- Синхронизация между устройствами
- Безопасная аутентификация

## Технологии

- React 19.1.1 + Vite 7.1.2
- Tailwind CSS 3.4.0
- Zustand (состояние)
- Supabase (база данных + auth)
- Recharts (графики)

## Требования

- Node.js 18+
- Аккаунт Supabase

## Установка

```bash
git clone https://github.com/your-username/qoder.git
cd qoder
npm install --legacy-peer-deps
```

### Настройка

1. Создайте проект на [Supabase](https://supabase.com)
2. Скопируйте `.env.example` в `.env` и заполните данными Supabase
3. Выполните миграции БД из папки `supabase/migrations/`
4. Запустите проект:

```bash
npm run dev
```

## Использование

1. Зарегистрируйтесь или войдите в аккаунт
2. Добавьте подписки через кнопку "Добавить подписку"
3. Просматривайте аналитику на дашборде
4. Управляйте подписками (редактирование, удаление, деактивация)

## Разработка

### Команды

- `npm run dev` - разработка
- `npm run build` - сборка
- `npm run preview` - просмотр сборки
- `npm run lint` - линтинг

### Структура

```
src/
├── components/   # UI компоненты
├── pages/        # Страницы
├── store/        # Zustand хранилище
├── services/     # API сервисы
└── lib/          # Утилиты

supabase/migrations/  # Миграции БД
```

## Развертывание

1. Создайте продакшн проект Supabase
2. Обновите переменные окружения
3. Выполните миграции БД
4. `npm run build` и разверните на Vercel/Netlify
